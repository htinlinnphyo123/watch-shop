# Stock barcode labels

Labels show the product name, model (when available), individual stock-unit barcode, and current selling price in MMK before checkout discounts. Foreign-currency prices use the same nearest-1,000 MMK rounding as POS; prices entered in MMK are preserved. This applies to existing individual/page watch labels and accessory labels through the shared label component.

On the Watch list, **Print all the labels** prepares one label per available watch stock unit across all pages and regardless of current filters, then opens the browser print dialog automatically. The browser still requires confirming the destination/printer. The preview remains available for reprinting if automatic printing is blocked by the browser.

Bulk watch printing excludes accessories, sold/reserved/returned/lost/damaged stock, deleted units, and deleted watches. Existing barcode values are retained, including leading zeroes. Available units missing codes receive generated unique codes; no new stock is created and stock statuses are not changed. Repeated printing reuses those codes. Admins and managers can print bulk and selected labels; staff cannot access these endpoints.

Printing uses a three-column layout with labels measuring exactly 60 mm wide × 25 mm high, including padding and dotted cut lines. The barcode occupies 56 × 12 mm inside each label. Long names and model numbers are shortened to one line to keep the label within its fixed size. Use A4 or Letter at 100% / Actual size with browser headers and footers off. Prices and availability reflect the snapshot taken when labels are prepared; reprint after changing prices or exchange rates. A large inventory produces a correspondingly large print job.

Use **Select barcodes to print** on the Watch list to combine individual available stock units from different models. Search by watch name, model, system code, or serial number; selections remain while changing searches and pages within the picker. **Select this page** adds only the visible results. Review selected units to remove individual entries or clear the selection, then **Print selected** prepares one label per chosen unit using the same three-column sheet. Up to 1,000 units can be selected per print job. Closing the picker keeps its selection while the Watch page stays mounted; navigating away resets it.

Browsing the picker does not generate codes. Printing generates missing codes only for selected units and preserves existing codes. Availability is rechecked when printing; if any selected unit was sold, reserved, or deleted, the entire request is rejected so no partial sheet is silently produced. Remove unavailable entries from the selection and try again.
